# Experiments

This directory records what happened after a proposal spends compute or tests a
claim.

Use one file per result.

Each entry should include:

- proposal or PR;
- git commit;
- config and seeds;
- W&B links when applicable;
- budget actually spent;
- metric and null or baseline;
- result;
- regime;
- verdict;
- what changes in `AGENTS.md`.

Negative or inconclusive results are useful. Record them plainly.

# Agent Instructions

- Follow `docs/process/METHOD.md` for implementation planning and review.
- Keep each change to one clear goal; split work when a title needs "and".
- For proposal work, use `docs/process/PROPOSAL_TEMPLATE.md`, keep proposals in
  `docs/proposals/`, and record experiment results in `docs/experiments/`.
- Use branch names `pr/<number>-<short-goal>` for PR work.
- Do not push directly to `main` unless the user explicitly asks for it.
